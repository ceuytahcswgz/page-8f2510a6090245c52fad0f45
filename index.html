02使用说明：按顺序做四件事

不跳步是最省时间的做法。下面四步按依赖关系排列，前一步没完成时，后一步通常也做不下去。

  1. 先定档位

    统计两件事：一个月大约用多少流量、同时要连几台设备。用这两项去对上面的套餐表，不要先看价格再看权益。

  2. 按所选档位确认额度

    流量按自然月计，设备数按「同时在线」计。手机与电脑各算一台，不要按「人」计算。

  3. 在设备上完成接入配置

    使用账户提供的接入信息，在你自己的设备上完成配置。配置完成后先做一次基本的连通性检查，再开始正式使用。

  4. 记录并维护

    把账户信息、所选档位、到期时间记在一个你能找到的地方。团队版涉及多人使用时，先确定谁负责统一配置，避免重复变更。

03客户端：按你自己的平台选

客户端以你自己设备上已有的系统能力为准。这里说明各平台需要注意的点，不提供未经核实的下载地址。

桌面端（Windows / macOS）

适合长时间在线与多窗口办公。配置完成后建议做一次重启验证，确认设置在重启后仍然保留。

获取方式：以账户页提供的说明为准

移动端（iOS / Android）

适合外出场景。注意移动网络下流量消耗明显快于 Wi-Fi，基础版的 100GB 在手机上要按实际使用节奏估算。

获取方式：以账户页提供的说明为准

路由器 / 团队统一配置

团队版支持企业定制路由。多人共用时先在路由器层面统一，比逐台设备配置更省事。

获取方式：随团队版服务一并说明

04常见问题：逐条编号，逐条回答

下列问题按被提问的频率排列。回答只涉及本页已写明的信息，未写明的部分我们不作推断。

  1. 三档套餐最核心的区别是什么？

    三件事：每月流量额度、同时在线设备数、线路类型。基础版 100GB / 3 台 / 普通线路；旗舰版 300GB / 5 台 / 含 IPLC 专线与全节点原生流媒体解锁；团队版 1000GB / 20 台 / VIP 专属高带宽节点并支持企业定制路由。

  2. 月付和按年付怎么选？

    只按你预计的持续使用时长选。三档的按年付价格分别为 ¥150、¥350、¥850，与月付之间的差额你可以自己算一遍再做决定。不确定会持续多久时，先用月付。

  3. 「同时在线设备数」怎么算？

    按同一时刻在线的设备数量算，不按账号数量算。手机、电脑、平板各计一台。团队版的 20 台同样按此口径。

  4. 流量每月用不完会累积到下个月吗？

    本页未承诺流量结转。请按自然月内的实际额度规划使用，不要把上月的余量计入本月。

  5. 旗舰版的 IPLC 专线适合谁？

    适合对线路类型有明确要求的使用者，例如需要更稳定线路特征的游戏场景。如果你的用途主要是网页与文档，基础版的普通线路节点池通常已经够用。

  6. 团队版的「企业定制路由」需要准备什么？

    先确定内部由谁负责统一配置、有哪些设备需要纳入，再与专属客户经理对接。本页不对定制范围作额外承诺，具体以对接时的说明为准。

  7. 支持哪些客户端和平台？

    页面内按桌面端、移动端、路由器与团队统一配置三类分别说明了注意事项。本页不提供下载地址，安装包与安装步骤请以账户内说明为准。

  8. 使用中遇到问题找谁？

    旗舰版含 7×24 优先工单支持，团队版含专属客户经理服务。基础版请按账户内提供的支持渠道提交问题。
